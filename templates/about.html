About ML Models We Have Trained

Logistic Regression is a powerful classification algorithm used to estimate the probability of a student passing or failing based on input features such as attendance, study hours, and academic scores. It works using a sigmoid function that maps input data into a probability value between 0 and 1. This model is efficient, easy to interpret, and performs well when the relationship between variables is linear. It serves as a strong baseline model in our system. However, its limitation lies in handling complex non-linear relationships, which may reduce performance in more dynamic datasets.

Decision Tree is a flexible machine learning model that splits data into branches based on feature conditions, forming a tree-like structure of decisions. It is highly effective in capturing non-linear relationships and interactions between variables such as study patterns and performance metrics. This makes it ideal for educational datasets where multiple factors influence outcomes. While Decision Trees are easy to visualize and interpret, they may overfit the data if not properly controlled. Combining it with Logistic Regression allows us to compare structured and probabilistic learning approaches effectively.
