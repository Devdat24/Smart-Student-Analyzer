📖 About This Project

The Student Performance Analytics System is a machine learning-based web application designed to predict a student's final academic performance. It uses a real-world dataset and applies data preprocessing, regression modeling, and visualization techniques to generate accurate predictions. The system is built using Flask (backend), HTML/CSS (frontend), and SQLite (database), making it lightweight and efficient.


🔧 Technologies Used:

Python, Flask, Scikit-learn, Pandas, SQLite, HTML, CSS
